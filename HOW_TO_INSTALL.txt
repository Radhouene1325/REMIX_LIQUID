========================================
⚡ QUICK START (5 MINUTES)
========================================

1. Open your theme in Shopify Admin:
   Online Store → Themes → Your Theme → Edit Code

2. Find layout/theme.liquid (or your main layout file)

3. In the <head> section, ADD:
   {{ 'mobile-performance.css' | asset_url | stylesheet_tag }}

4. Before </body>, ADD:
   {{ 'performance-optimization.js' | asset_url | script_tag }}
   {{ 'web-vitals-monitoring.js' | asset_url | script_tag }}

5. Upload the 3 JS/CSS files to Assets folder

6. Save and Publish

7. ✅ DONE! Your theme is now optimized.
